# うんちインクリメンタル 仕様メモ

## ゴール
- Steam配信を目指す、うんちを題材にしたインクリメンタルゲーム
- 見た目は粗目のピクセル調でポップな雰囲気
- 「5分遊んで、もう少し触りたくなる」を最重要基準にする

## コアループ
1. キャラが歩く
2. 立ち止まって踏ん張る
3. うんちを出す
4. プレイヤーがクリックして回収し、うんPが増える
5. うんPでスキルを買い、1に戻る

## 用語
- ポイント名：「うんP」（読み：うんぴー）
- 転生用ポイント：「お花ポイント（仮）」

## 画面構成
- 中央：フィールド（キャラとうんちが動く）
- 上部：うんP表示（所持数、毎秒増加量）
- 右側：スキルツリー（「スキルツリーへ」ボタンで移動、裏でフィールドが動き続ける）
- 下部：設定、セーブ、実績など

内部解像度480×270を整数倍拡大で表示（ドットがにじまない）。

## 数値設計
- スキル費用は購入のたびに約1.15〜1.8倍（スキルにより異なる。詳細はskill-tree.md）
- 数字表示はK/M/B/T単位
- うんPと金うんPの2種類のポイントを持つ

## 未回収のうんち
- 初期は出現から一定時間（試作では2秒）で消える
- スキル「残留時間延長」で段階的に延長
- 肥料化→花→お花Pの仕組みは、うんP収集と目的が競合するため、いったん取り除いた（素材のたんぽぽ・肥料は保持しているので、将来の再利用は可能）

## 金のうんちと転生
- 金のうんちは、スキル「金のうんち解放」（試作では2,000うんP）を買うと出現し始める。初期の出現確率は1%。「金のうんち確率アップ」（1,500うんP〜、増加率1.6、上限10段階）で、1段階あたり+0.4%、最大5%まで上がる
- 金のうんちを回収すると、通常のうんPに加えて金うんPが1貯まる（手動・自動回収どちらでも）
- 転生に必要な金うんPは、回数を重ねるごとに増える（試作v4では 30×2.2^回数）。最初の転生は、赤鬼を解放できるくらいの進行度で可能になる想定
- 選び方はカード選択型（B案）：転生時にカードが提示され、1つを選ぶとそのボーナスのレベルが上がる
- 転生すると、うんP・スキル購入状況（金のうんち解放を含む）・キャラ解放状況・自動回収などは初期化される。金うんPの残り、転生ボーナスのレベル、転生回数は引き継ぐ
- ボーナス候補（試作v4時点）：うんP獲得量アップ（+8%/回）／残留時間ボーナス（+0.3秒/回）／自動回収強化（速度・範囲+10%/回）。数値感は検証を続ける
- 除外したもの：スタートダッシュ（今の成長を捨てるメリットが薄いため）、肥料化時間短縮（お花システムの除去に伴い削除）
- 候補が3種類だと、毎回同じ3枚が並ぶ。ランダム性を出すには、候補の追加が必要（未決定）

## ゲームの終わり方（未確定）
- 案1：終わりなし。伝説キャラを全解放するとエンディング演出＋実績、その後も遊べる
- 案2：ローグライト的に、うんPでレベルアップしてキャラ追加やスキル強化のカードを選んでいき、全キャラコンプ or 全転生ステージクリアで終わる
- 細部は試作でテストプレイしながら決める

## セーブとオフライン
- 自動セーブを一定間隔で行う。手動セーブも可
- オフライン進行はスキルで効率アップ。Steam版はクラウドセーブを追加

## 画面遷移・UI方針
- スキルツリーは2カラム（キャラクター柱／プレイヤー柱）を1画面に収める
- キャラごとの個別スキルはアコーディオンで畳む
- スキルツリー画面表示中も、裏でフィールドが動き続ける

## 開発方針
- HTML/JavaScript（Canvas）で試作し、Steam化の段階でElectron＋steamworks.jsで包む
- ゲームエンジン自体は未決定
- 素材はdotown（https://dotown.maeda-design-room.net/）を基本にする。他サイトも規約確認の上で併用可
- 規約上、必要なものが揃わない場合のみAI生成素材を使う。仕様確定後、SteamのAI生成コンテンツ規約を確認する
